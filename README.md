## Синтаксис

| Запись | Значение |
|---|---|
| `a` | символ |
| `ab` | конкатенация |
| `a\|b` | объединение |
| `a*` | звезда Клини |
| `(a)` | группировка |
| `(a\|)` | ε как пустая ветвь |
| `\*` | экранирование: любой символ после `\` — обычный |

```
union  := concat ('|' concat)*
concat := star*
star   := atom '*'*
atom   := letter | '(' union ')'
```

Пробелы вне экранирования игнорируются: пробел как символ пишется `\ `.

## Требования

- **g++ 14+** или **clang++ 18+** — проект собирается как C++23 (`-std=c++23`).
- **gcovr** — нужен для отчёта о покрытии (`gcov` берётся рядом с компилятором).
- CMake 3.25+.
- GoogleTest скачивается автоматически при конфигурации (`FetchContent`).

Проверьте версию компилятора: `g++ --version`.

## Примеры

`formal_print` печатает каноническую запись регулярки:

```sh
build/debug/examples/formal_print 'a|bc*'
```

С флагом `--dot` он печатает дерево разбора в формате Graphviz:

```sh
build/debug/examples/formal_print --dot 'a|bc*' | dot -Tsvg -o tree.svg
```

Для просмотра картинки нужен установленный `graphviz`.

## Сборка и тесты

Проект собирается через CMake-пресеты: `debug`, `release`, `sanitizers`, `coverage`.
Компилятор задаётся через `CXX` (без него CMake выберет компилятор по умолчанию):

```sh
# конфигурация + сборка + тесты одной командой
CXX=g++ cmake --workflow --preset debug
CXX=clang++ cmake --workflow --preset debug
```

Если компилятор в системе называется иначе, укажите его имя: `CXX=g++-14`.

То же по шагам:

```sh
CXX=g++ cmake --preset debug  # конфигурация → build/debug
cmake --build --preset debug  # сборка
ctest --preset debug          # тесты
```

Для релизной сборки замените `debug` на `release`.

## Санитайзеры

Debug-сборка с AddressSanitizer и UBSan:

```sh
CXX=g++ cmake --workflow --preset sanitizers
```

## Статический анализ

```sh
cmake --build --preset tidy
```

## Покрытие

```sh
CXX=g++ cmake --workflow --preset coverage
```

HTML-отчёт:

```sh
xdg-open build/coverage/coverage/index.html
```

> `CXX` учитывается только при первой конфигурации. Если компилятор был выбран
> неверно, удалите каталог `build/<preset>` и запустите конфигурацию заново.
