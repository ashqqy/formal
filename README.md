# formal

## Требования

- **g++ 16+** — проект использует статическую рефлексию C++26 (`-std=c++26`), которая есть только в GCC 16 и новее.
- **gcov той же версии**, что и g++, плюс `gcovr` — нужны только для отчёта о покрытии.
- CMake 3.25+.
- GoogleTest скачивается автоматически при конфигурации (`FetchContent`).

Проверьте версию компилятора: `g++ --version`.

## Сборка и тесты

Проект собирается через CMake-пресеты: `debug`, `release`, `coverage`.
Компилятор задаётся через `CXX` (без него CMake может выбрать другой, например clang):

```sh
# конфигурация + сборка + тесты одной командой
CXX=g++ cmake --workflow --preset debug
```

Если GCC 16 в системе называется иначе, укажите его имя: `CXX=g++-16`.

То же по шагам:

```sh
CXX=g++ cmake --preset debug  # конфигурация → build/debug
cmake --build --preset debug  # сборка
ctest --preset debug          # тесты
```

Для релизной сборки замените `debug` на `release`.

## Покрытие

```sh
CXX=g++ cmake --workflow --preset coverage
```

HTML-отчёт появится в `build/coverage/coverage/index.html`.
Версия `gcov` должна совпадать с версией `g++`, иначе `gcovr` не сможет прочитать данные покрытия.
Если `gcov` по умолчанию другой версии, укажите его через `GCOV`:

```sh
CXX=g++-16 GCOV=gcov-16 cmake --workflow --preset coverage
```

> `CXX` учитывается только при первой конфигурации. Если компилятор был выбран
> неверно, удалите каталог `build/<preset>` и запустите конфигурацию заново.
